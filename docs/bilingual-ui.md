# 界面双语与术语表（P2-6）

状态：已落地（`web/src/i18n.ts` + `i18n.zh.ts` / `i18n.en.ts` + `glossary.ts`）。

## 1. 为什么双语不是"再加一份翻译"

这个工具里的关键词大多是**自造词**（债务、验收面、上浮、下沉）或**被改写含义的词**
（宪法、验收、阻塞、休眠、预授权）。两类都会让外部使用者按日常意思理解，而
**错理解不会产生任何报错** —— 表现是"我照着它说的做了，结果全错"。

所以两件事必须成对做：

| 做的事 | 少了它会怎样 |
|---|---|
| 界面可切语言 | 非中文使用者第一步就卡住（连"绑定工程"都不敢点） |
| 术语表 | 译文里的自造词仍然猜不出来，翻译反而给了虚假的安全感 |

**只做其中一件都是半成品**：只切语言，译文里的 obligation 会被读成"待办"；
只做术语表，没人找得到它在哪。

## 2. 覆盖范围是**声明**出来的，不是猜的

`web/src/localized.ts` 有两份清单：

| 清单 | 含义 |
|---|---|
| `LOCALIZED` | **承诺**：这些文件的界面文案已经全部走词典 |
| `PENDING` | 还没转的文件（诚实记录进度，不是"以后再说"） |

规矩：**只把已经全部转好的文件放进 `LOCALIZED`**。为了让测试变绿而塞进去，
会让这份清单从"承诺"退化成"现状描述"，测试也就没意义了。

`PENDING` 的顺序按优先级：面板（用户直接看得到）在前，`App.tsx` 最后
—— 它的拆分属于 P5-2，那时一起转才不会白做一遍。

## 3. 八条不变量（`web/src/i18n.test.ts` + `i18n.detect.test.ts`）

每条都**能真的红**（已用变异测试逐条验证，见 §4）。

| 编号 | 不变量 | 不钉住会怎样 |
|---|---|---|
| L1 | 两种语言**键完全一致** | 漏译的键静默回落成另一种语言，界面半中半英 |
| L2 | 词典里**不许有空串** | 空串渲染成"这里什么都没有"，比漏译更难查 |
| L3 | `LOCALIZED` 声明的文件里**不许有字面文案** | "改了中文忘英文"是静默的：中文用户永远看不到这个 bug |
| L4 | 键的命名空间与三段组名**都必须已登记** | 键名漂移后没人找得到一条文案在哪 |
| L5 | 界面根节点**真的挂了** `I18nProvider` | 漏挂 = `useI18n` 抛错；错挂 = 界面凭空变中文 |
| L6 | 术语表每条都**指得到 SPEC**，双语文本都写全 | 术语表变成第二份真源，与 SPEC 悄悄分叉 |
| L7 | **切换语言真的会改文案** | 开关看起来能点，实际什么都没变 |
| L8 | 词典里**没有孤儿键**、代码里**没有幽灵键** | 打错的键名运行时拿到 `undefined`，界面上是一片空白 |
| D1–D3 | 语言检测：存过的优先 / 按系统语言 / 取不到时回落而不崩 | 用户每次刷新都被掰回系统语言；隐私模式下白屏 |

L3 与 L8 是这套机制里**唯一会随代码增长而失效**的两条，所以它们扫源码，
不依赖人的记性。

## 5. 加东西时的操作顺序

**加一条界面文案**：

1. 往 `i18n.zh.ts` 加键（写中文，说清代价，不要用恒真的词）；
2. `i18n.en.ts` 会因类型不匹配而**编译失败** —— 这比"记得去加"可靠；
3. 组件里用 `t('…')`；
4. 跑 `pnpm test`：L8 会核对这个键真的被用到。

**新转一个组件**：

1. 把它的文案全部搬进词典；
2. 从 `PENDING` 移到 `LOCALIZED`；
3. 跑 `pnpm test`：L3 会核对没有漏掉的字面文案。

**加一个新语言**：

1. 新建 `i18n.<lang>.ts`，类型为 `Record<DictKey, string>`（漏键即编译失败）；
2. 在 `i18n.ts` 的 `LANGS` / `LANG_LABEL` / `HTML_LANG` / `DICTS` 四处登记
   —— 测试会核对四处齐全；
3. **术语表还要补一份说明文本**（`glossary.ts` 的 `TermText` 目前是
   `{zh, en}` 两语言）。这是已知的扩展点：上第三种语言时要把 `TermText`
   改成 `Record<Lang, string>`，并把 `pick` 一起改 —— 不要在 `pick` 里加
   `if (lang === 'fr')` 之类的分支，那会把语言数量硬编码进读取路径。
